# Resume_AI
Project description will be expanded upon further at a later point

# Problem Statement
I have seen many free online AI resume parsers with restrictive character limits and limited uses.  This can be a massive issue, especially for new-grads or those without the resources to have their resumes looked at by industry professionals.  To fill the gap, this program will allow a user to parse through their resume to find gaps the ATS may flag.

# Planned Description
This is the repository for a free open source AI model to parse through a Resume and give recommendations based on 
1) How ATS-friendly it is
2) How close it is to the desired job description

# Tech Stack 
Language: Python
Libraries: LangChain and Hugging Face Transformers
